# 轻单 · 协作画布

从 `D:/TODO` 提取的独立画布项目。保留原来的便签、清单、图片编辑、灵感板和收纳，新增邀请加入、实时协作、在线成员、冲突处理和断线恢复。原项目和原浏览器数据库未修改。

## 本地运行

本机开发需要 Node.js 24 或以上，以及与 `runner/protocol-version.json` 一致的 Codex CLI。

```powershell
cd D:\TODO\qingdan-canvas
npm ci
npm run dev
```

打开 <http://127.0.0.1:8790>，也可以双击 `启动协作画布.cmd`。`npm run dev` 同时构建并启动网页、Worker 和本机 Agent，自动应用本地 D1 迁移。已有的 <http://127.0.0.1:8788> 网页也能自动连接 Agent，无需切换网址。无需登录 Cloudflare。

1. 首次打开填写用户名、邮箱和密码，发送并输入邮箱验证码后注册；已有账号直接登录。注册成功时邮箱已绑定，可用于找回密码。登录后创建一张画布，无需共用创建口令。
2. 添加便签、清单，拖入图片；已同步表示服务器已确认保存。
3. 点击“邀请协作”，复制链接。在另一个浏览器打开并登录另一个账号，即可作为另一位成员加入。
4. 同一台电脑可用普通窗口和无痕窗口测试；地址 `127.0.0.1` 只指向当前电脑，不能直接发给异地同伴。正式部署后使用线上地址。
5. 刷新会恢复此标签页的草稿；离线、上传失败、冲突都会显示提示。未同步时不要关闭标签页，先导出备份。

编辑代码后运行 `npm run build` 更新网页；需要前端热更新时，保留 Worker 服务，另开终端运行 `npm run dev:ui`，访问 Vite 输出的地址。

新账号注册需要邮件服务。本地开发可参照 `.dev.vars.example` 在未跟踪的 `.dev.vars` 中配置 Resend 与验证码密钥；不配置时旧账号仍能登录，新注册会提示邮件服务尚未启用。自动化测试使用独立的模拟邮件服务，不会发送真实邮件。

## 开场封面

网站入口 `/` 显示「灵感墙 + 杂志封面」，同时在后台准备登录页或协作空间。准备期间显示「正在准备你的空间…」，首屏就绪后才启用「打开我的空间」；点击或键盘激活后，沿用退出动画并切换到 `/app`，直接展示同一个已准备好的页面。连接失败或等待超过 20 秒可在封面重试。开启系统「减少动态效果」时仍需等待就绪并点击，随后直接进入。

协作空间使用 `/app`，画布与排列界面使用 `/app?room=…`。直接访问、刷新或应用内导航均不显示封面，并沿用已有草稿设置恢复画布/排列模式。浏览器前进、后退会按地址恢复页面；主动返回 `/` 才重新展示封面。旧的 `/?room=…` 链接会规范化到新地址并保留邀请信息，新邀请使用 `/app`。专用 MCP 授权页面继续直接展示原有登录/授权流程。

封面图片随站点发布，来源与许可保存在 `public/opening/`。本次界面改动无需数据库迁移。

## 轻岛（Windows 桌面悬浮窗）

保持轻单本机服务运行（`npm run dev`），进入网页画布后点击顶部「轻岛」，即可沿用当前账号和画布直接显示桌面胶囊，无需再次登录或选择画布。网页不再提供页内灵动岛模式，旧的开启偏好也不会显示网页浮层。同一画布重复点击只唤起原窗口并保留输入；切换账号或画布时先保存，有未提交或未同步内容则确认。首次启动会下载 Electron 运行环境。也可在同一项目执行 `npm run desktop`，命令入口仍保留独立登录、选择画布流程；启动成功后额外终端可以关闭。

进入画布后窗口收成桌面顶部胶囊，使用其他软件时仍然置顶。悬停或点击展开，拖动握柄、图标或标题可切换停靠边；松手时以当前屏幕中心判断方向，自动吸附到顶部、左侧或右侧，无需拖到边缘，不保留自由悬浮位置。左右停靠时收成窄侧签。支持选择项目、勾选完成、新增待办和钉住。面板提供返回画布列表、在浏览器打开完整画布和隐藏到托盘。托盘菜单可再次显示、恢复顶部位置、重新连接或「退出轻岛」。退出轻岛不会停止轻单服务。

桌面待同步内容使用独立且稳定的本地草稿身份。退出前等待本地保存；存在未同步内容或未提交输入时提示确认。未提交输入只在当前窗口保留，隐藏不会丢失，确认退出会丢弃。详细启动、恢复和本地数据位置见 [轻岛说明](docs/desktop-island.md)。

## 画布与排列

线上及预览环境保留「Agent」入口，点击仅显示「Agent 正在开发中」和返回画布按钮，暂不开放操作。恢复旧 Agent 视图也只显示该提示。服务端同时拒绝 Agent、Runner 和执行接口，并保持旧 Agent DO 的定时任务与连接停用。本地开发（`APP_ENV=local`）继续提供完整 Agent；现有功能开关不能绕过线上限制。

顶部「Agent」进入项目聊天、真实待办、记忆与批次执行工作区；仅「Agent 验证」按钮及旧八步验证页面已移除。使用 Node.js 24 和项目锁定版本的 Codex，先运行 `npm run agent:install`，再运行 `npm run agent:start`，打开 <http://127.0.0.1:8790>。重复启动会复用已确认身份的实例。此入口复用本地轻单账号和数据，线上账号与本地数据库相互独立。开发时仍可运行 `npm run dev:agent`；两种入口不能同时占用端口。详细操作见 [安装与故障恢复](docs/agent-installation.md) 和 [Agent 功能说明](docs/agent-experience.md)。

运行 `npm run agent:diagnose` 查看安装与就绪状态，或在 Agent 的电脑设置中检查诊断与恢复。普通 `agent:stop` / `agent:restart` 会拒绝中断未完成或状态不明的执行；`--interrupt-active` 明确中断活跃任务，不是续跑命令。异常退出后重新 `agent:start`，回到原执行核对进度，避免再次提交同一待办。卸载入口 `npm run agent:uninstall` 默认保留数据、日志及凭据。

创建者可点击首页画布卡片右上角或工作区顶部名称旁的铅笔，修改项目名称（1–80 字）。保存后列表与当前标题更新，其他成员重新打开项目时可见新名称；项目内容和邀请链接保持不变。

在首页点击自己的昵称进入「账号设置」，可上传、更换或移除头像。支持最大 20 MB 的 PNG、JPEG、WebP、GIF 原图；圆形选区可扩大至编辑区四边，并可缩放原图。保留图片比例，圈内留白与圈外区域透明，裁剪后压缩为 256×256 的 WebP 图片，GIF 使用静态画面。每条待办显示创建者的图片头像，没有上传时显示昵称首字；旧待办会从完整的历史操作记录补回创建者，无法确认作者的条目仍显示问号。重写文字保留原创建者。顶部「作者头像」开关只控制当前账号在当前画布中的显示，关闭后仍可在待办菜单查看创建者。个人画布可以继续邀请协作者。

顶部的「画布 / 排列 / Agent」切换同一份内容的视图。排列顶部以浏览器标签页的形式切换项目（灵感板），当前项目的未完成待办全部放在左侧，已完成待办全部放在右侧。勾选时保留抬起、划线和落位动效，从左栏飞入右栏对应位置。Agent 中提交所选待办后，同一批次按顺序使用同一 Codex 会话，逐项验收及回写后才继续。

- 顶部「帮助」打开简短的功能 tips；画布和排列模式都可查看。
- 普通便签按整篇文章编辑：粘贴长文保留换行与空行，回车在正文内换行；双击正文后 Ctrl / ⌘ + A 全选整篇、Ctrl / ⌘ + C 复制。已有多段便签也使用同一个编辑区，无需重新粘贴。
- 排列中的普通便签整篇作为一个待办，可整体勾选完成、设置截止时间、排序、复制和删除。正文默认只显示一行，超长文字在鼠标停留时横向滚动，双击后展开全文编辑和复制；清单仍按事项逐条排列，「本页资料」只放图片。
- 左侧「灵感板」与 Ctrl + 左键框选使用相同的底色和缩放方式；按钮新建的板会避开已有灵感板，并显示完整的右下角手柄。
- 元素拖入灵感板时，板轻微放大提示，松手即可放入；移出后在画布空白处停稳 1 秒再松手，元素才脱离灵感板，提前松手会返回板内。普通分组仍需停留 2 秒才能放入。
- 画布右键选择「删除此元素」时，便签、图片或整个灵感板会揉成纸团并飞入左上角收纳箱；内容可从箱中取回，也可撤销。系统设置减少动态效果时跳过动画。
- 画布清单只通过复选框切换完成状态；单击文字不再勾选，双击仍可编辑。
- 点击顶部的项目标签切换两栏内容；标签过多时可横向滚动，也可用方向键、Home / End 切换。点标签旁的「+」新建灵感板，下面的工具栏可重命名或收纳当前灵感板。只有一个项目时仍保留未完成和已完成两栏。
- 「未分组」也可通过标签菜单重命名或删除。重命名会将其中内容整理成普通灵感板并保留画布位置；删除经确认后将内容移入回收站，有锁定内容时须先解锁。空的「未分组」不显示标签，仍可直接添加待办；新增未归组内容后会再次出现。
- 点击「添加待办」输入；回车保存，Shift + Enter 换行，多行文字会拆成待办。双击正文或点铅笔编辑，编辑中回车增加下一项，输入两个左方括号 `[[` 选择引用。
- 未完成栏的「DDL 排序」按截止时间从早到晚排列，无截止时间的待办放在最后；相同时间保留原顺序。点击只排序一次，之后可直接拖动待办上下调整，修改截止时间不会自动重排。顺序随待办同步保存，也可撤销；有锁定待办时先解锁再排序。
- 日历第一次点击选择单日，第二次点击较晚日期形成区间，点击较早或相同日期重新选单日；区间形成后再点击也重新选单日。区间从起始日零点到结束日选择的时间，保存、同步、撤销和重开都保留两端，月历覆盖整个区间。
- 灵感板、画布便签与清单抬头显示浅色创建时间；排列每条待办显示其创建时间，DDL 仍由右侧日历按钮设置。
- 「常用清单」保存在当前账号的 D1 数据中，仅本人可读写；同一账号的多个画布与设备共用。打开时自动迁入当前浏览器此前按该账号保存的模板，每次点击模板都会创建独立的新待办。保存失败会保留输入并提示重试，模板最多 100 条。
- 收纳箱入口只在画布模式显示，排列和运维资产界面隐藏入口；收纳内容保留，切回画布即可取回。
- 运维服务器使用同一套 DDL 日历、时分滚轮和日期区间选择。产品目录按绑定服务器逐项显示日期，同一服务器的多个部署只显示一次；日期修改或服务器删除后自动更新。运维记录沿用当前浏览器的本地存储。
- 右键待办只出现紧凑的「删除」菜单，不再叠加浏览器菜单；点击空白处或按 Esc 关闭。
- 保留勾选、备注、待办菜单、图片资料、收纳与取出。收纳行按钮会收纳该便签的全部事项；行菜单和 Delete 只删除所选待办，回收站与撤销可恢复。
- N 在左侧新增未完成待办，Ctrl / ⌘ + A 选择当前操作栏的事项，Delete 删除选中行，Ctrl / ⌘ + Z 撤销。输入框内仍使用正常文字编辑快捷键。
- 当前项目和模式保存在当前浏览器标签页的视图偏好中；旧的双项目偏好自动沿用上次操作的项目。协作者可以使用不同视图；新增、编辑、勾选等内容仍实时同步。切换视图不改变画布已有位置、尺寸和缩放。
- 排列新增内容会放到对应灵感板中，并在必要时扩展板的边界。无需增加 Cloudflare 资源或数据库迁移。

## Agent / MCP 接入

Router 第 1 步已实现共享任务规则：执行要求、验收条件、依赖校验、稳定排序、手工顺序校验与时区转换。运行 `npm run test:agent` 验证，详细字段、接口和范围见 [任务规则说明](docs/agent-task-rules.md)。本步骤尚未接入真实清单或网页操作入口，后续按 [实施计划](docs/superpowers/plans/2026-11-03-qingdan-router.md) 继续。

第 2 步已接通本机 Codex：独立总结/任务会话、流式结果、原会话续聊、审批、取消和历史恢复。真实三会话与文件交接验证通过。Runner 需要 Node.js 24，先执行 `npm ci --prefix runner`，再运行 `npm run runner:build` 和 `npm run test:runner`；环境、复验命令和证据见 [本机 Codex 兼容性记录](docs/agent-codex-compatibility.md)。设备配对与网页入口按后续步骤接入。

远程 MCP 提供九个读取搜索、待办和便签工具，使用轻单账号 OAuth、逐画布授权、只读/读写权限与服务端删除恢复；改动共用网页版本和实时同步机制。默认关闭，启用须配置专用 OAuth KV 和固定 HTTPS origin。

按 [四客户端接入指南](docs/mcp-setup.md) 配置 Codex、Claude Code、VS Code GitHub Copilot 或 Cursor；维护者阅读 [环境配置](docs/mcp-configuration.md) 与 [Cloudflare MCP 发布步骤](docs/cloudflare-setup.md#轻单-mcp-升级与发布)。[验收记录](docs/mcp-acceptance.md) 区分本地自动验证、界面检查以及尚未运行的四端/云端验收。当前分支仅完成本地构建与验证，没有部署或真实客户端登录。

## Cloudflare 产品分工

| 产品            | 保存或处理什么                                                    | 绑定     |
| --------------- | ----------------------------------------------------------------- | -------- |
| Workers         | 网页静态资源、会话、权限、邀请和图片 API                          | `ASSETS` |
| Durable Objects | 每画布独立房间；WebSocket 同步、对象版本、操作回执、SQLite 持久化 | `ROOMS`  |
| D1              | 账号、密码哈希、登录会话、画布目录、成员、邀请摘要、图片元信息    | `DB`     |
| R2              | 图片原文件，经过成员鉴权后读取                                    | `FILES`  |

画布对象正文的权威副本位于 **Durable Object 的 SQLite**，D1 存目录与成员。无需手动创建每个 DO，Worker 会按画布编号定位实例。

## 当前边界

- 邀请链接授予编辑权限。创建者可重置邀请；已经加入的成员保留权限。当前没有成员移除、只读邀请、账号找回或邮箱登录。
- 用户名不区分大小写，为 3–32 位英文字母、数字、下划线或短横线；密码为 12–128 个字符。昵称支持中文。登录会话有效期 30 天，账号和云端内容不随 Cookie 到期而删除；换设备登录同一账号即可取回已同步内容。
- 点击首页右上角昵称进入账号设置，可以修改昵称、修改密码、退出登录。修改密码后其他设备需重新登录；当前暂不支持邮箱找回密码。
- 首次升级时，在原浏览器注册并勾选认领旧画布，可保留创建者身份；登录已有账号也可合并该浏览器的已同步旧画布。需要仍有效的旧 Cookie；已清除或过期的旧身份无法自动认领。登录已有账号前请先备份未同步访客草稿。
- 本地和生产环境都要求账号登录。旧的 `CREATE_KEY` 不再参与画布创建；保留线上 secret 不影响使用。升级顺序为 `npm run db:remote`，再 `npm run deploy`，均由你手动执行。
- 常用清单账号存储需要 `0005_account_quick_tasks.sql`；本地 `npm run dev` 自动应用，正式更新时仍先迁移 D1 再部署。
- 文字以事项/字段为单位合并，**不是字符级 CRDT 编辑器**。同时修改同一句话时会提示冲突；双方不同字段、不同事项通常可自动合并。先导出草稿，再选择冲突内容。
- 视口、选择、撤销历史和回收记录属于本地用户。共享删除会同步；回收站恢复来自当前浏览器记录。
- PNG、JPEG、WebP、GIF，单图最多 10 MiB；不接收 SVG。基础限制：单画布 2000 个对象、50 个 WebSocket 连接，每次原子修改最多 200 个对象。
- 本轮没有自动导入原工作区、部署公网服务、创建远程资源或接入模型/本机执行器。

## 验证

```powershell
npm test
npm run check
npm run deploy:check
```

`npm test` 包含原画布回归、同步协议、冲突/撤销，以及自动启动真实本地 workerd 的集成测试。集成测试使用独立 `.tmp/integration-*` 数据目录，不碰开发画布。

`deploy:check` 只构建并打包，不部署。`npm run deploy` 会拒绝使用占位 D1 ID 或本地开发模式。
