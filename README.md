# 轻单 · 协作画布

从 `D:/TODO` 提取的独立画布项目。保留原来的便签、清单、图片编辑、灵感板和收纳，新增邀请加入、实时协作、在线成员、冲突处理和断线恢复。原项目和原浏览器数据库未修改。

## 本地运行

需要 Node.js 22 或以上（开发时使用 Node.js 24）。

```powershell
cd D:\TODO\qingdan-canvas
npm ci
npm run dev
```

打开 <http://127.0.0.1:8788>，也可以双击 `启动协作画布.cmd`。启动器会构建网页、应用本地 D1 迁移，再启动 Worker。无需登录 Cloudflare。

1. 在首页右上角设置昵称，创建一张画布。
2. 添加便签、清单，拖入图片；已同步表示服务器已确认保存。
3. 点击“邀请协作”，复制链接。在另一个浏览器打开，即可作为另一位成员加入。
4. 同一台电脑可用普通窗口和无痕窗口测试；地址 `127.0.0.1` 只指向当前电脑，不能直接发给异地同伴。正式部署后使用线上地址。
5. 刷新会恢复此标签页的草稿；离线、上传失败、冲突都会显示提示。未同步时不要关闭标签页，先导出备份。

编辑代码后运行 `npm run build` 更新网页；需要前端热更新时，保留 Worker 服务，另开终端运行 `npm run dev:ui`，访问 Vite 输出的地址。

## 画布与排列

顶部的「画布 / 排列」切换同一份内容的两种视图。排列沿用原 Agent 左侧清单界面，左右各打开一个灵感板，分别显示未完成和已完成事项；不包含聊天、模型配置或 Codex 执行功能。

- 点击两栏顶部的灵感板名称切换页面；选择另一栏正在显示的板时，两栏互换。只有一块板时，可用另一栏的「新建灵感板」补充。
- 点击「添加待办」输入；回车保存，Shift + Enter 换行，多行文字会拆成待办。双击正文或点铅笔编辑，编辑中回车增加下一项，输入两个左方括号 `[[` 选择引用。
- 保留勾选、备注、待办菜单、图片资料、收纳与取出。收纳行按钮会收纳该便签的全部事项；行菜单和 Delete 只删除所选待办，回收站与撤销可恢复。
- N 在当前操作栏新增待办，Ctrl / ⌘ + A 选择本栏所有事项，Delete 删除选中行，Ctrl / ⌘ + Z 撤销。输入框内仍使用正常文字编辑快捷键。
- 两栏选择和模式保存在当前浏览器标签页的视图偏好中。协作者可以使用不同视图；新增、编辑、勾选等内容仍实时同步。切换视图不改变画布已有位置、尺寸和缩放。
- 排列新增内容会放到对应灵感板中，并在必要时扩展板的边界。无需增加 Cloudflare 资源或数据库迁移。

## Cloudflare 产品分工

| 产品            | 保存或处理什么                                                    | 绑定     |
| --------------- | ----------------------------------------------------------------- | -------- |
| Workers         | 网页静态资源、会话、权限、邀请和图片 API                          | `ASSETS` |
| Durable Objects | 每画布独立房间；WebSocket 同步、对象版本、操作回执、SQLite 持久化 | `ROOMS`  |
| D1              | 画布目录、匿名会话、成员、邀请摘要、图片元信息                    | `DB`     |
| R2              | 图片原文件，经过成员鉴权后读取                                    | `FILES`  |

画布对象正文的权威副本位于 **Durable Object 的 SQLite**，D1 存目录与成员。无需手动创建每个 DO，Worker 会按画布编号定位实例。

## 当前边界

- 邀请链接授予编辑权限。创建者可重置邀请；已经加入的成员保留权限。当前没有成员移除、只读邀请、账号找回或邮箱登录。
- 匿名身份跟随当前浏览器 Cookie，有效期 90 天。清除 Cookie 或换浏览器，需要重新使用邀请加入；此时不会自动继承原创建者身份。请保管邀请与备份。正式账号体系可在下一阶段连接 Cloudflare Access。
- 生产环境创建画布需要 `CREATE_KEY` 口令。加入已存在的画布只需邀请链接。本地启动显式启用免口令开发模式。
- 文字以事项/字段为单位合并，**不是字符级 CRDT 编辑器**。同时修改同一句话时会提示冲突；双方不同字段、不同事项通常可自动合并。先导出草稿，再选择冲突内容。
- 视口、选择、撤销历史和回收记录属于本地用户。共享删除会同步；回收站恢复来自当前浏览器记录。
- PNG、JPEG、WebP、GIF，单图最多 10 MiB；不接收 SVG。基础限制：单画布 2000 个对象、50 个 WebSocket 连接，每次原子修改最多 200 个对象。
- 本轮没有自动导入原工作区、部署公网服务、创建远程资源或接入模型/本机执行器。

## 验证

```powershell
npm test
npm run check
npm run deploy:check
```

`npm test` 包含原画布回归、同步协议、冲突/撤销，以及自动启动真实本地 workerd 的集成测试。集成测试使用独立 `.tmp/integration-*` 数据目录，不碰开发画布。

`deploy:check` 只构建并打包，不部署。`npm run deploy` 会拒绝使用占位 D1 ID 或本地开发模式。

## 文件

- `src/canvas/`：提取的画布交互和数据模型。
- `src/App.jsx`、`src/CanvasWorkspace.jsx`：画布列表与协作界面。
- `src/sync/`：本地草稿、WebSocket 状态机、合并和撤销。
- `worker/`：Worker API、D1 成员检查、R2 文件和 DO 房间。
- `shared/`：前后端共用的画布对象校验。
- `migrations/`：D1 建表迁移。
- `wrangler.jsonc`：可部署的资源绑定，占位 D1 ID 待填写。
