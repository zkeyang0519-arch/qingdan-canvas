# MiSans web fonts

Xiaomi MiSans, subset webfont distribution pinned to misans@5.0.0 (font 4.009).

Source: https://github.com/dsrkafuu/misans
Official font: https://hyperos.mi.com/font
Fonts copyright: Xiaomi Inc. See FONT-LICENSE.pdf for the official MiSans Font Intellectual Property License Agreement, downloaded unchanged from https://hyperos.mi.com/font-download/MiSans%E5%AD%97%E4%BD%93%E7%9F%A5%E8%AF%86%E4%BA%A7%E6%9D%83%E8%AE%B8%E5%8F%AF%E5%8D%8F%E8%AE%AE.pdf.

The separate LICENSE file is the upstream distribution scripts' Apache-2.0 license; it is not the font license. Qingdan's Agent settings include visible MiSans attribution and a link to the font agreement.

Bundled weights: Normal 350, Regular 400, Medium 500. Original WOFF2 files and Unicode ranges are unchanged; CSS URLs point to local assets.
