# Noto Sans SC variable web fonts

This is the same Noto Sans SC family selected in the Qingdan font preview, distributed as @fontsource-variable/noto-sans-sc@5.3.1.

Source: https://www.npmjs.com/package/@fontsource-variable/noto-sans-sc/v/5.3.1
Font project: https://github.com/notofonts/noto-cjk

Original WOFF2 files and Unicode ranges are unchanged. The generated CSS only changes URLs to local assets. Variable weights: 100–900; the Agent UI uses 350 body, 400 controls, 600 section headings and 650 emphasis.
