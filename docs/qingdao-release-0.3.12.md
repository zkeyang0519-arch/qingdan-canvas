# 轻岛 0.3.12

此版本目前提供未签名 Beta 验收包；正式版尚未发布。Beta 使用独立应用、更新渠道和用户目录，不替换现有正式版。

- 设置分为对话模型、工具与 Agent、个人偏好；现有模型连接与 MCP 选择保留。Codex 的执行偏好放回服务详情，其他 Agent 可通过 MCP 添加。
- 项目资料集中展示概览、交接报告、来源、生成记录及约定与经验。普通聊天无需先生成摘要。
- 待办直接在原行编辑；执行权限收为一个入口，展开后仍提供完整的四种模式。
- 任务完成后可用当前模型进行一次有上限的复盘。明确长期要求和有验收依据的方法可保存，推测内容仅生成建议；可以编辑、忽略、撤销或关闭自动整理。
- 轻岛可启用内置本地服务，界面、Worker、Runner、Pi 与 Node 运行时随同一个安装包升级。已有独立服务继续使用，轻岛不会关闭独立运行的 Codex。
- 更新后台下载，完成后点击“重启并更新”；有任务时可预约并取消。安装前暂停派发、等待任务、保存草稿与检查点、确认受管服务退出，再安装并自动重启。
- 保存失败或服务状态不明确会停止安装，保留当前应用与下载包，显示恢复或重试入口。远端任务保留原回执，不自动重复提交。

验收使用隔离账号、目录及模拟远端服务。真实模型和 WAAO 付费生成不在这轮验收中调用。Windows 正式发布需要配置代码签名，同时同步安装包、blockmap、latest.yml 和官网下载页；测试版使用 beta.yml。
