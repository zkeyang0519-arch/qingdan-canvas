# 一次提交一个会话：批次模式验收

日期：2026-11-05（Asia/Shanghai）。本机轻单已加载修改，未部署生产。Codex 版本 0.166.0-alpha.6。

## 用户可见行为

进入 **Agent 验证 → 4 · MCP 派单**，添加多条待办，为各项填写要求和完成标准，用上移/下移排好顺序，再点击 **提交批次**。一个提交对应一个批次和一个 Codex 会话，各项分别在该会话的新一轮中执行。下一次提交使用新会话。

派单记录显示每项状态与结果。前一项有效 done 后才发送下一项；每轮只传当前项，不提前发送后续项的文字。阻塞、无效结果或交互等待会暂停；补充继续当前项；停止要确认当前轮与后台命令已结束，再停止后续队列。完成和停止后的批次不追加新任务，原有无 batch 的单条运行保留兼容。

侧栏归组及此前失败的目录刷新保持停用。正式清单的自动写回、聊天整理需求不包含在本次交付中。
