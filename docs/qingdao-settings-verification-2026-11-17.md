# 轻岛设置弹窗与历史预览

本文记录设置弹窗初次实现时的本地验收。后续与两版配色联合合并的范围和验证见 `qingdao-settings-main-verification-2026-11-17.md`；没有发布新的客户端或生产网页。

## 交互

- 小仓悬停继续展开待办；点击原有滑杆设置按钮，把双舱下方的区域切换为设置弹窗。横向、左侧、右侧均保留双舱。
- 设置采用浅色毛玻璃底色以保证控件可读；上方双舱继续实时显示所选颜色和透明度。沿用原有本机外观存储键，不迁移或覆盖旧偏好。
- 点击打开的设置保持展开；返回按钮或 Escape 返回待办，恢复焦点和未提交输入。窗口失焦、收起和拖动仍使用既有行为，系统原生调色窗口不触发误收起。
- 检查更新调用现有 bridge.checkForUpdates，订阅真实状态，处理进行中、下载、已就绪、不支持和失败反馈。迟到的状态查询不会覆盖较新的事件；不会因为一次检查失败显示“已是最新版本”。联合合并时已在版本更新栏加入「重启更新」，调用同一原生安装和保存流程。
- 历史菜单包含 v0.3.1–v0.3.6，每个选项都有图片。选择仅改变预览图，不安装旧版、不切换当前外观、不写待办数据。

## 历史图片

`public/island-releases/v0.3.1.jpg` 至 `v0.3.6.jpg` 均由对应 Git 发布标签内的真实 React 组件和 CSS 渲染，使用隔离的内存示例待办，包含横向、侧边和展开状态。

准备页面：`node scripts/build-island-history-previews.mjs`。在本地预览服务的 `/history/v0.3.N.html` 页面，以 800 × 400 页面区域截图。图片总计约 85 KB。

桌面打包静态资源处理器增加 `/island-releases/` 与 JPEG MIME，历史图片随 dist 打入客户端，在离线时也由本地安装包读取。原有 API 转发和路径边界不变。
