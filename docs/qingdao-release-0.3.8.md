# 轻岛 0.3.8：逐条设置截止日期

## 功能

- 展开列表的每条待办右侧增加常驻日历按钮，支持设置、修改与清除截止日期及时间；已设置时显示剩余时间、临近和超时状态。
- 日历与时间滚轮复用画布现有组件，在轻岛面板内部呈现，沿用窗口自动测量及滚动，不向原生可点击区域外弹出。
- 点击日期按钮不勾选完成；取消与 Escape 保留原日期、待办文本和新增输入，并返回列表。编辑期间悬停移出不自动收起，切换项目及收起后不保留未确认的日期草稿。
- 保存复用 `setPageDeadline` 与当前工作区同步，保留 UTC 日期区间及协作冲突检查。只读、最新锁定、删除和远端日期变化均不会被旧界面覆盖。
- 保持 0.3.7 的林间苔绿、色块流动、清透玻璃、两版独立调色和检查更新。
