# 第五步：真实清单验收

日期：2026-11-05（Asia/Shanghai）。本机轻单已更新，未部署生产。运行时为 Windows、Node.js 24.18.0、Codex 0.166.0-alpha.6。

## 入口与行为

刷新本机轻单，进入 **Agent 验证 → 5 · 真实清单**，选择实际清单分组及其第3步本机项目绑定。可创建真实待办、保存执行要求和完成标准、上下移排序、选择未完成且可派单的条目，然后一次提交一个批次。源待办使用真实 canvas/note/task ID，不再复制到验证草稿。

一次提交仍只创建一个 Codex 会话，各待办按保存顺序逐轮执行。面板可查看批次、停止、打开会话以及清单回写结果。即使执行中全部源待办被移走，原批次仍保留在历史并可停止。

默认勾选 **执行成功且待办未变化时自动勾选完成**；关闭则只执行而保留清单状态。自动勾选依据受信 Runner 对当前有效轮次提交的 done 执行回执；这不声称系统已独立代替人类验收所有质量条件。本次测试另外实际核对了输出文件。

每次回写在画布事务内核对当前源待办、语义版本、执行规格、锁和所属分组，只更新 done/completedAt。用户修改、删除、移动或重新打开待办后，旧结果不能覆盖当前状态。重复回执不会再次勾选；短暂失败只重试画布同步，不重跑 Codex。
