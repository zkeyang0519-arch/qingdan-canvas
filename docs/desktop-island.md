# 轻岛

轻岛是 Windows 桌面悬浮窗，复用轻单真实账号、画布与待办同步；网页仅保留「轻岛」启动入口，不再显示页内灵动岛浮层。默认连接原项目本机服务，不会另启或关闭 Runner。

## 启动

在 `D:\TODO\qingdan-canvas` 中运行：

```powershell
npm ci
npm run dev
```

保持服务终端运行，在本机网页进入画布，点击顶部的 **轻岛** 按钮即可沿用当前账号和画布，直接出现桌面胶囊，无需再次登录和选择画布。同一账号和画布已有窗口时只会唤起原窗口，保留未提交输入；切换到另一账号或画布时，先保存原来的修改，有未提交或未同步内容则默认保留原画布，用户确认后才切换。8790 本机入口及 8788/5178 开发网页均可使用；线上网页会提示打开本机入口。

首次会下载固定版本 Electron 运行环境，按钮会显示启动中；下载完成后打开桌面窗口。也可以继续用同一目录下的命令启动：

```powershell
npm run desktop
```

命令启动成功后不必保留这个额外终端。也可提前执行 `npm run desktop:install` 下载运行环境。若服务尚未运行，桌面窗口会显示启动指引和「重新连接」。按钮要求本机轻单服务已启动且网页已登录；它不负责启动或停止 Runner。

网页启动会由本机服务验证当前会话与画布权限，再经一次性交接让桌面窗口使用同一会话；不会读取浏览器 Cookie 数据库，不会把凭据放进网址、命令行、环境变量、普通日志或交接文件，也不会交给网页 JavaScript。桌面自身的 Cookie 仍由 Electron 管理。共享会话在一端退出登录或被撤销后，另一端也会在重新校验时失效；从网页再次点击可接入当前有效账号。

直接使用 `npm run desktop` 命令时仍可自行登录和选画布。桌面连接本地轻单，线上与本地账号/数据按原项目规则分别管理。

## 使用

- 切到其他普通桌面软件后，胶囊仍然置顶。
- 悬停/点击展开，移开或窗口失焦后收起；钉住可保持展开。
- 拖动胶囊的握柄、图标或标题区域可切换停靠边，按钮、勾选框和输入框不会带动窗口。
- 松手时以光标所在屏幕的可用工作区中心判断方向，自动吸附到顶部、左侧或右侧，无需拖到边缘。向上方向区域归顶部，其余按左右位置归侧边；下半区也归左右侧，不停靠底部任务栏。轻岛只在拖动过程中跟随鼠标，松手后始终贴边。
- 顶部保留横向胶囊并向下展开；左右收成窄侧签，分别向右、向左展开。旧版保存的自由悬浮位置会在重新打开时自动吸附。
- 侧签显示剩余待办数，悬停、点击文字区域或箭头都可展开；整个侧签正文可拖动。拖动期间收起面板，释放后恢复钉住状态，未提交输入保留。
- 停靠边与位置会保存，重新打开后恢复。托盘「恢复到屏幕顶部」可找回窗口。
- 勾选、新增、项目切换复用已有同步与锁定保护。Enter新增，Shift+Enter换行。
- 面板返回按钮可切换画布或进入账号设置；右侧按钮在普通浏览器打开完整画布。
- 「隐藏到托盘」和窗口关闭操作保留当前窗口。托盘图标可再次显示。
- 托盘「退出轻岛」会先等待本地保存，有待同步修改或未提交输入会确认。保存失败不会自动退出。未提交输入没有跨进程保存保证，确认退出会丢弃；已保存的待同步内容在重新打开对应账号和画布后恢复。

## 排障与数据

首次升级到支持免登录交接的版本，如果旧桌面主进程仍在运行，网页会提示它未响应交接。请从系统托盘安全退出一次轻岛，再点网页按钮；关闭窗口只会隐藏，不能更新主进程。新版只在桌面确认当前账号、画布和胶囊布局已就绪后显示成功，不会把进程刚启动当作交接完成。

升级到支持自由拖动与侧边停靠的版本也需要从托盘退出旧桌面一次，再点网页的「轻岛」。普通网页刷新无法更新已运行的桌面主进程；退出前请处理未提交输入，已同步待办和登录状态保留。

`8790 EADDRINUSE` 表示轻单服务已运行，不需要再执行第二次 `npm run dev`。源码服务诊断：

```powershell
node scripts/agent-install.mjs diagnose --source
```

需要重启服务时先用 `node scripts/agent-install.mjs stop --source` 安全停止，确认无活动任务后再启动。桌面窗口本身不会终止这些服务。

运行日志在 `.tmp/desktop-profile/desktop.log`；桌面登录、IndexedDB 草稿、位置等保存在 `.tmp/desktop-profile/`。不要为了排障删除这个目录，它可能保存尚未同步的内容。运行环境在 `node_modules/electron/dist`。这些内容不提交到 Git。

开发隔离验证可设置 `QINGDAN_DESKTOP_URL` 为随机端口的本机 HTTP `/app` 地址，`QINGDAN_DESKTOP_PROFILE` 为单独测试目录。不要对真实桌面档案做故障注入。只允许本机地址，当前不提供远程网址加载、自动更新或已签名安装包。

置顶适用于普通桌面窗口；系统安全桌面或独占全屏不在本版保证范围。实现使用 [Electron 原生窗口](https://www.electronjs.org/docs/latest/api/base-window)和[隔离的 preload](https://www.electronjs.org/docs/latest/tutorial/security)，待办仍走原有同步服务。
