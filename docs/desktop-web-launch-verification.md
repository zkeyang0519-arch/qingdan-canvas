# 轻岛 0.3.1 网页安装与更新入口验收

日期：2026-11-14。

## 实现

- 网页点击轻岛后通过固定协议唤起安装版，优先使用 8791 独立入口；无独立入口时兼容现有 8790 本机服务。
- 本机服务检查安装和发布版本，首次下载、校验并安装；版本一致直接启动，版本较新不降级。更新源失败但已有安装时明确提示后使用现有版本。
- 有新版时先下载和校验，再保存登录、待办和未提交输入，安全退出、安装、启动；安装器不强制结束仍在运行的进程。
- 独立安装版由网页触发版本检查和自动安装；网页等待新进程及新的画布交接成功后才报告已打开。
- 没有任何本机软件时提供官方发布页下载入口；浏览器不能静默执行首次 EXE，用户运行安装包后页面自动继续连接。
- 安装器注册 `qingdao://open`。网页不能传入任意下载地址、执行命令、安装参数或读取本机登录 Cookie。

## 尚需上线后验收

改动整理在 `codex/qingdao-install-update` 分支，尚未合入 main，GitHub 尚无桌面 Release；因此上述验证不等于公开更新源已经启用。仍需将版本代码上线、创建对应桌面 Release，再用两个递增的公开版本验证真实下载、安装重启与状态恢复。

0.3.0 没有自动安全退出接口，首次切换到 0.3.1 需从托盘正常退出；这不会通过强制结束进程绕过。首次安装时的 Windows/浏览器授权提示仍由用户决定。有效会话可以保留，但服务端已过期或撤销的会话不能由更新程序延长。
