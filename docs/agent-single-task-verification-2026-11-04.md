## 结果

- 新任务用户消息只包含当前执行要求原文；补充说明只包含补充原文。
- 验收标准、项目背景与执行规则分别通过独立上下文和会话配置传入，不拼进用户消息。
- 新会话通过 `qingdan_report_result` 提交机器回执，最终回复为自然语言。
- Runner 等轮次结束后读取完整顺序历史，只采用最新用户消息之后的成功回执，再补全可信任务编号。缺失/无效回执、失败、取消和补充之前的旧回执不能判为完成。
- 服务重启后恢复同一会话，动态工具沿用持久化定义，执行规则与任务背景重新传入。
- 旧会话保留原来的 JSON 兼容方式；新格式从新派发的任务开始使用。第 4 步完成后仍显示“本轮结束，待你验收”，未擅自完成后续步骤的清单自动写回。
