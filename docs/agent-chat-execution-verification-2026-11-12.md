# Agent 项目聊天执行验证

日期：2026-11-12。

## 已实现行为

- 工作区移除右侧独立执行进度区和聊天上方当前事项框，用户与助手分别使用气泡。
- 从右侧提交时，以 `executionMode: project` 将所选待办和已保存项目信息写入同一次执行快照；一次启动 Codex，不自动逐项续发，也不将汇总结果当作逐项验收证明。
- 同一聊天记录呈现提交正文、附带项目信息、助手正文、命令输出、文件变更及最终结果。旧运行仍可读取、停止或恢复。
- 输入区提供开始／停止；停止确认前维持停止中，普通聊天取消后保留已有正文，禁止迟到回复覆盖取消结果。
- Markdown 支持标题、嵌套列表、任务列表、引用、表格、链接及带复制功能的代码块；原始 HTML 不执行，危险链接不开放。

## 后续调整：节点流式与程序记录折叠

按用户要求，将已收到的正文按字符逐步显示，并按助手节点组织执行过程。默认只展开当前节点；节点下只显示最近更新的一条程序行，较早节点、命令输出和文件修改记录可以主动展开。历史结果、停止后的内容和系统减少动态效果模式直接显示完整文本，较长的新输出会加速追上，避免动画积压。

新节点出现时自动收起上一节点；主动查看旧节点或程序记录时停止自动跟随到底部。已经显示完的结果重新展开时不重播动画。完成回执按当前执行轮次读取，避免上一轮结果盖住新输出；成功回执与详细最终回答不同的时候，保留详细回答，将回执放入可展开入口。
