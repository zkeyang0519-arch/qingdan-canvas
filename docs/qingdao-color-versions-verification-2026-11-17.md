# 轻岛两版配色接入

已接入实际 `DynamicIsland` / `TwinIslandHeader` 组件和原有轻岛设置面板。本文记录配色初次接入时的验收；后续联合合并见 `qingdao-settings-main-verification-2026-11-17.md`。尚未部署生产网页或覆盖已安装的客户端。此前的独立 HTML 配色预览保留。

## 外观与调色

- 默认「清透玻璃」：保留增强后的边缘折射和白色高光，林间苔绿色块为 `#DAE5CD`、`#AEC59A`、`#8AAA76`；小舱为 `#CBD9BF`，流动周期 9 秒，玻璃强度 90%。
- 「色块流动」保留备注选定的原版；两版共用同一个色块场算法，玻璃只改变边缘采样并叠加表面反光。
- 两版均可选择林间苔绿、春芽微光、雾感鼠尾草、抹茶奶绿和之前调的原色，编辑原生颜色输入或 HEX，增删 1–8 个色块，独立调整小舱颜色、流动周期及开关。玻璃版另有强度滑杆。
- 新设置在 `qingdan.desktop.island-appearance.v2` 中按版本分别保存；旧 v1 配色键原样保留。恢复当前外观不重置另一版，不写画布、待办或输入草稿。
- 低分辨率色块缓冲区放大到设备像素画布，每秒最多绘制 30 帧。小舱静态渲染；关闭动效、窗口隐藏、组件离屏或系统减少动态效果时停止循环，卸载释放观察器和动画帧。
- 所有装饰层都在原有圆角舱内裁剪，不拦截鼠标；保留原有几何尺寸、原生命中区域、小猫、拖动、悬停和任务操作。
