# 轻岛 0.3.10

- 鼠标停在显示时间和待办数量的小舱上，待办会在原位展开。修复了顶部和侧边停靠时窗口左右跳动的问题。
- 展开后单击同一个小舱，会用系统默认浏览器打开当前待办所属的画布。面板上的收起按钮、Esc 和移出收起仍可使用。
- 手动运行 Windows 安装包时，首次安装可以选择目录，再次安装可以覆盖已有版本或更换安装位置。保存检查、程序解压和安装完成有对应的进度提示。

已有用户可以在「轻岛设置 → 检查更新」中下载，然后点击「重启更新」。自动更新沿用原安装目录，你的草稿、待办和外观设置保存在原有用户资料中。也可以从[轻岛下载页](https://todo.zky.lol/download/)手动下载安装。
