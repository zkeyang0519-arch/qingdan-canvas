4. 在 `thread/start` 时指定已登记目录对应的后台项目编号，也未能自动归组。测试会话 `01a1a5f1-21a9-7192-bf78-da282fc719fb` 只回复固定文字，无文件修改；后台正确记录 projectId，而桌面归属仍为空。
