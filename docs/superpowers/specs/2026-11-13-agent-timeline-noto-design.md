# Agent 思源黑体与任务时间线

用户已在交互预览中选择「任务时间线＋重点增强＋思源黑体」，并明确要求直接应用到轻单，正文保持 14px。此记录是已批准设计的落地说明，不再增加确认步骤。

## 已选设计

- 使用预览相同的 Noto Sans SC Variable（思源黑体版本），固定 Fontsource 5.3.1，原始 WOFF2 子集随应用本地托管。
- 正文 14px / 350 / 1.85，关键词 650；主标题 18px / 650，小标题 15px / 600。
- 正文色 #56625a，重点色 #172b1e，辅助信息保留低视觉权重。
- 用户气泡与助手内容均为可用聊天区的 80%；助手输出无外框；输入框 14px。
- 保留居中轻弹窗、现有项目工具、流式输出、复制和引用、真实状态与执行控制。

## 方案比较

已展示编辑式阅读、任务时间线、双栏提要。用户选任务时间线；随后选重点增强和五字体预览中的思源黑体。编辑式和双栏方案不实施。

## 内容适配

预览中的固定示例不能作为真实执行数据。实际回复根据原有 Markdown 的同级标题或带粗体标题的无序列表形成时间线，保留原文、顺序和语义。总标题与开头结论置于节点前；嵌套列表、代码、表格、普通段落保持原有格式。

时间线节点仅表示内容分组，使用中性圆点，不凭文本推断成功、失败或进度。执行记录沿用真实 run 状态及现有展开/折叠逻辑。用户消息和摘要弹窗不自动变成时间线。

## 验收

验证标题分组、带标题列表、普通内容不误分组、流式更新不丢文、引用/代码/任务列表保留语义。运行仓库要求的 npm test、npm run check、npm run deploy:check。浏览器核对本地字体加载、桌面和窄屏的字号/字重/宽度、无横向溢出，以及登录账号和电脑在线状态。

范围为本地轻单；真实部署按仓库说明由用户操作。保留工作区已有其他修改，不创建提交。
