## 实现原则

沿用当前 React、Workers、Durable Objects、SQLite 和 Codex app-server 协议。在原有状态机上修复持久化与生命周期边界。各功能可以单独读取状态、显示依赖故障，并提供明确的恢复动作。执行仍要求有效账号、项目授权和可验证的停止事实。

采用当前代码的隔离 Git 工作树作为实现区，基于原工作区全部可跟踪文件建立基线。通过验证后仅把修复差异同步回原工作区，若源文件同时被修改则按三方内容合并。

新增回归只覆盖具体审计缺陷和必要的跨节点恢复。使用随机端口、临时项目和隔离数据库。真实用户设备绑定、凭据与活动服务不用于故障注入。操作系统整机重启和真实模型任务的故障验证单独报告覆盖边界。
