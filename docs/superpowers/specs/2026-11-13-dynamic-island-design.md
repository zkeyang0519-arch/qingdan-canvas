# 轻单网页灵动岛

用户在查看胶囊交互预览后，要求从 Agent 开发分支另开 feature 分支开发。本次授权覆盖创建分支与实现预览行为。

- 分支：`feat/agent-dynamic-island`；基于 `feat/qingdan-mcp` 的已提交版本 `ea47f8b`，独立 worktree。原目录未提交内容不复制、不修改。
- 在工作区顶部提供「灵动岛」开关。保留画布、排列与 Agent 视图，开启后在导航下方浮现胶囊。
- 胶囊显示首个未完成任务和完成数；悬停/点击展开、离开延迟收起、可钉住，Escape 收起并归还焦点。触屏可点击外部收起。
- 展开后显示明确项目名及项目选择、真实任务、快速新增、同步状态和关闭入口。默认沿用排列所选项目；不宣称跟随 Agent 自己的项目选择。
- 勾选调用现有 workspace.toggleBlock；新增通过 createObject/makeBlock/appendPageObjects，并基于最新状态重查锁定/项目存在。保留同步、作者、撤销以及草稿机制。一段多行输入生成一条待办。
- 开启状态与钉住保存到现有账号/画布隔离的本机视图偏好；项目选择沿用 choosePanePage。默认关闭，不改共享画布模式。
- 冲突只读、锁定、收纳或删除的项目不得被岛写入。新增失败保留草稿；草稿按项目隔离，切换/远程项目删除不能把草稿写到其他项目。
- 320px、长文本/长列表、输入法、键盘、减少动态效果必须可用；岛内快捷键不能误触画布的删除/选择。
- 不增加依赖、服务端接口或迁移。无桌面系统置顶、客户端打包、发布或远程推送。

## 方案选择

沿用已预览的网页浮层。浏览器画中画和桌面壳不属于这次授权效果。作为现有视图的可选浮层比新增互斥视图更贴近预览，也保留现有编辑器与聊天状态。
