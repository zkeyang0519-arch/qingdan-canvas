# 排列模式待办与系统剪贴板互通

## 已确认的需求

在 `feat/qingdan-mcp` 分支实现：外部文字可以粘贴进排列模式待办，待办文字可以复制到外部软件。用户明确要求：一次粘贴只生成一个待办，多行文字保留在同一条中。

## 建议采用的交互

- 列表空白处增加右键「粘贴为待办」。右键粘贴和 Ctrl / ⌘ + V 使用相同规则：整段纯文字生成一条未完成待办，保留换行、空行和列表文字；空白内容不创建待办。
- 新建待办输入框粘贴多行文字，保存后仍为一条待办。正在编辑已有待办时，文字插入光标处或替换所选文字，保留当前待办的身份、备注、日期及完成状态，不拆分成新待办。
- 待办右键菜单增加「复制文字」，复制完整正文及换行，保留现有删除入口。复制成功后可以在外部软件右键粘贴。编辑文字时使用浏览器原生右键菜单，支持选择部分文字后复制，以及在光标处粘贴。
- 只读或锁定内容仍可复制，粘贴写入遵循现有编辑权限。剪贴板读取期间切换项目、画布或账号时，取消该次插入，避免写入错误目标。
- 浏览器拒绝自定义菜单读取剪贴板时，提示使用 Ctrl / ⌘ + V；复制失败提供可选中的完整文字以便手动复制，不提示虚假的成功。

## 实现方式与取舍

建议组合使用原生编辑菜单与现有任务菜单：编辑区交给浏览器处理光标和文字选区，非编辑区提供「复制文字」「粘贴为待办」。只放开原生菜单无法提供整条待办复制和空白处创建；全部改成自定义菜单则需要额外管理选区与浏览器权限。组合方案复用现有交互，改动较小。

复用现有任务数据、保存、协作同步和撤销逻辑，仅为排列模式添加单条粘贴规则。共享编辑器通过显式选项启用该规则，不改变画布模式或常用清单模板原有的按行导入行为。不新增依赖、数据库字段或服务端接口。

## 验证

覆盖空白处、草稿输入框、已有待办编辑三个粘贴入口，多行和列表文本只产生一条待办；完整文字及换行可以复制；编辑区原生菜单不被拦截；原有删除、只读、锁定、导航及其他模式仍正常。验证剪贴板权限失败和读取期间目标变化，并运行全量测试、类型检查与部署演练。浏览器验收使用隔离测试数据。
