# Agent 界面整理

范围：本批第 1 项，整理本机 Agent 界面并提供实际预览。基于当前工作树，保留既有业务、数据、权限、摘要与执行流程；不启动下一项，不发布生产。

## 设计选择

采用现有三栏工作区的渐进整理：安静的浅灰绿导航、集中阅读的白色聊天区、独立的待办与执行侧栏。相比重做成仪表盘，这个方案保留操作习惯；相比仅替换配色，它改善长文本阅读、操作分组和窄屏空间。这是本轮实现选择。

灵感：[Linear 的界面整理](https://linear.app/now/behind-the-latest-design-refresh)，参考主次层级、较轻的分隔与一致的工具位置，沿用轻单的绿色品牌。

## 具体呈现

- 导航中统一项目选中状态、数量与留白；顶栏将项目资料和连接设置分组。
- 桌面聊天正文居中、限制阅读宽度，统一消息身份标识、空状态、输入区和发送按钮。
- 待办操作对齐，执行区以步骤和当前项突出状态；不隐藏审批、失败或恢复提示。
- 桌面三栏，窄屏保留项目选择及聊天/待办切换；短窗口和长标题不挤掉输入、工具或滚动区域。
- 使用现有 React、lucide-react 和 CSS，不添加依赖。

## 验收

现有交互回归、类型检查、全量测试、部署预检；本机浏览器检查桌面与 390px 窄屏，保留截图和可打开的预览。测试状态隔离，不修改真实任务或设备绑定。未实测项如实记录。
