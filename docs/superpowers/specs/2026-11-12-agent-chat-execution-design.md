# Agent 项目聊天执行

按用户本轮五项要求，在现有工作树实现：右栏保留待办编辑与提交；移除独立执行进度、执行信息及顶部当前事项框；用户与助手使用独立气泡；执行全过程进入左侧项目聊天。

提交所选待办时，将完整待办快照和已保存项目信息一次交给 Codex，使用单次项目执行，不再逐项续发。运行和事件继续使用现有持久化、授权、幂等及停止协议。历史顺序执行仍能读取和停止。整组结果不能充当各待办已验收证据，因此新模式不自动勾选单项完成。

聊天显示提交正文、助手增量文本、命令输出、文件变更和最终结果；用户回看时不抢滚动位置。输入区统一提供开始／停止；停止回执未确认前保持停止中，保留已产生输出。普通需求讨论也支持流式正文与取消，提案在完整校验后出现。

正文采用安全 Markdown 渲染，包含标题、列表、代码、引用、链接和表格。桌面与窄屏共享同一聊天记录；不发布生产，不使用真实任务测试。
