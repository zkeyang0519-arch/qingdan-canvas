# 独立 Codex 连接程序

用户要求先单独把连接 Codex 的程序做完整、验证后再谈轻单集成。本次交付一个 Windows 本地可启动程序：自动发现本机 Codex，建立 app-server stdio 连接，显示协议与账号状态，读取/搜索/翻页本机历史会话，查看选中会话的项目目录。所有连接检查均为只读，不创建会话或发送模型任务。

程序包含本地浏览器面板、仅监听 127.0.0.1 的受保护 API、后台只读 Codex 客户端，以及可直接运行的便携包。便携包携带 Node 运行时，用户已有 Codex 时无需安装 Node/npm。源码和测试放在项目独立的 codex-connector 目录，运行数据与轻单完全隔离。

自动发现按显式路径、上次可用路径、环境/PATH、已知安装位置及 Windows 应用元数据进行。显式路径错误要提示修正，不能悄悄切换另一个配置。路径、版本、握手、账号状态、会话读取分别检查。首版兼容当前项目已经验证的 Codex 版本，未知版本明确提示；手动指定路径不会绕过检查。

连接故障采用有上限的重连；请求有超时；并发重试合并；重复启动复用已有实例；退出仅停止本程序启动的 Codex 子进程。读取失败保留可见结果但标注过期；未登录、路径错误、版本不符、协议异常和进程退出分别显示修复入口。没有历史会话是正常空状态。

面板提供重新检测、手动路径、清除路径偏好、搜索/分页、连接检查结果和脱敏诊断导出。浏览器请求需要随机访问凭证、严格本机 Host/Origin 校验；不提供任意 JSON-RPC 透传或执行命令接口。凭证不进入诊断，不输出 Codex 原始 stderr、登录 token 或历史正文。

验收：模拟真实 stdio 子进程测试成功、超时、畸形响应、崩溃、未登录、空会话、分页、路径失效、重复连接/启动和 API 越权；再用本机真实 Codex 验证自动发现、账号检查、会话列表/项目读取、重连和便携包启动。只以实际完成的验证报告交付，不承诺未经测试的新电脑、版本或平台。

范围决定：本轮集中于连接与只读会话访问，保留轻单云端、正式账号配对、自启动安装服务及任务执行为后续独立阶段；用户不会在这一步再次遇到轻单账号归属导致的“电脑未连接”。
