# 轻岛始终贴边

用户要求：以电脑中心判断轻岛所在方向，上方吸附顶部，左右吸附对应侧边，不能停在桌面任意位置。

- 沿用已存在的顶部胶囊和左右窄侧签，拖动松手时自动选择停靠边；不增加可关闭吸附的开关。
- 以光标所在显示器的可用工作区中心为原点，将横纵位移分别按半宽、半高归一化。向上位移大于等于横向位移时归顶部，否则按横向位置归左或右。中心点归顶部，下半区按左右归侧边。
- 鼠标拖动中仍跟手；松开、失焦结束拖动后只能停靠 top/left/right。
- 首次启动默认顶部；旧 free/无 dock 的位置按窗口中心迁移到对应边，已有合法停靠边保持。取消拖动返回原停靠位置。
- 多显示器、显示器移除和工作区尺寸变化使用目标显示器工作区。保留展开收起的稳定锚点。
- 继续保留轻岛名称、同账号/画布启动、置顶、草稿、钉住和同步回执。
