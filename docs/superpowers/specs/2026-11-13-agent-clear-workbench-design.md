- 项目选择、摘要、记忆、电脑设置共用居中弹窗。按内容高度收拢，长内容在窗口内滚动，保留关闭、Escape、焦点恢复及原生审批优先级。

- 提供真实回答复制与引用到现有草稿；输入区展示当前项目与摘要状态。仅呈现已接通的功能，不把预览里的示例附件或示例变更面板当成产品能力。
- 保留现有 API、持久草稿、项目绑定、记忆作用域、任务确认和执行语义。
