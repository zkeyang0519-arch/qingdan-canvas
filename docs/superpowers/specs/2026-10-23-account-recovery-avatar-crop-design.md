# 邮箱找回密码与头像裁剪

## 需求与选择

用户要求登录页增加忘记密码，以及上传头像后可调整圆形范围、缩放原图，仅保存圈内内容。用户已选择“绑定邮箱，通过邮件验证码重置”。现有项目为 React + Cloudflare Workers / D1 / R2，账号仅有用户名和 scrypt 密码。

曾考虑管理员一次性重置链接；用户选择邮箱验证码，以支持自行找回。实现沿用现有框架，邮件适配器默认 Resend（实现选择），不引入前端邮件密钥或第三方裁剪依赖。先完成本地代码与验证，生产迁移、发信域名验证、密钥配置和发布遵循项目的手动部署流程。

## 邮箱与找回

- 账号设置增加邮箱绑定；输入当前密码、邮箱，发送六位验证码，确认后才写入已验证邮箱。同一邮箱只绑定一个账号；现有邮箱在新邮箱验证完成前保留。
- 登录页增加“忘记密码”，输入用户名、绑定邮箱，发送验证码，输入验证码和两次新密码，成功后回到登录页。未绑定邮箱的旧账号需要先登录补绑，不提供仅凭用户名改密。
- 验证码十分钟有效、一次性、最多五次尝试、六十秒重发间隔，另有 IP、账号及邮箱频率限制。数据库只保存验证码 HMAC；服务需要独立的 EMAIL_CODE_SECRET、RESEND_API_KEY、EMAIL_FROM。
- 找回发送接口统一响应，不能泄露用户名或邮箱是否注册。验证码不出现在 HTTP 响应、日志或源码中。发信失败不会留下可用验证码。
- 验证码绑定用途、账号、邮箱及签发时的密码；改密或改绑后旧凭证不能继续找回。D1 原子批次消费验证码、更新密码并撤销全部旧会话；并发重复提交只允许一次成功。
- 邮箱仅通过本人资料接口读取，不扩展协作者公开资料。未配置邮件时清晰提示服务尚未启用，不影响现有注册登录。

## 头像

- 选择图片后展示本地裁剪编辑器，确认前不上传。可拖动圆圈、改变圆圈大小、放大缩小原图；支持鼠标与触屏，并提供可访问的缩放/范围控件。
- 圈外遮罩与圆形预览表达最终内容；导出 256×256 的透明背景圆形头像，圈外像素不保存。裁剪不得越出图片有效边界。
- 保留 PNG / JPEG / WebP / GIF、5 MB 上限和 GIF 静态帧规则。取消不改变旧头像，失败保留裁剪便于重试；切换账号期间不能误写另一个账号。

## 验收

邮箱绑定/找回成功、错误和过期验证码、五次限制、重发失效、唯一邮箱、身份切换、重复及并发提交、邮件错误、无邮件配置、旧会话撤销。头像覆盖取消、拖动/调整范围/缩放、边界、真实二进制上传、资源释放、失败恢复。运行 npm test、npm run check、npm run deploy:check，并检查桌面和窄屏 UI。
