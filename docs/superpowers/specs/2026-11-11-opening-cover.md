# 轻单灵感墙开场封面

用户已确认「个人灵感墙 + 杂志封面」方案，删除中央卡片右上角的「私人灵感集」。本次在 `feat/arranged-project-labels` 接入，验证后合并 `main`；不引入 Agent 开发分支。

## 行为

- 普通网页每次完整打开时显示封面，保持等待；只有点击中央卡片或使用键盘激活按钮才进入应用。
- 点击后卡片放大、周围图片退开，约 1.25 秒后露出原有登录页或协作空间。进入过程中应用开始加载，但不可交互。进入后不重新挂载应用。
- 减少动态效果时仍需点击，点击后立即进入。动画事件缺失、图片失败均不阻止进入。
- 完整保留 `?room=...#invite=...`；OAuth 专用 `/mcp/consent` 页面直接沿用原有流程。
- 完整复用现有登录、权限、邀请、画布与排列逻辑；不改 Worker、数据库或 Agent。
- 支持 320px 宽度、桌面与触屏；装饰图片不进入键盘焦点或朗读顺序。
- 图片随站点发布，保留原 Codrops 示例的来源、固定版本和许可说明。

## 已选方案

灵感墙使用图片、海报、书封与手绘卡片。中央入口使用米白纸面、宋体「轻单」、细框、页边厚度、圆形箭头；保留「让灵感，有处安放。」和「打开我的空间」。已比较的磨砂玻璃、叠页方案不纳入本次实现。

## 发布边界

将封面作为独立 React 入口包装层；正常路径在用户点击前不挂载 App，因此不提前加载会话或兑换邀请。现有 MCP 授权路径绕过包装层。用户已授权提交并合并 `main`，直接 Cloudflare 部署仍遵循仓库约定。
