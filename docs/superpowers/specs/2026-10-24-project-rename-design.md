# 修改项目名称

用户要求新增项目名称修改功能。现有云端项目对应 `rooms`，首页卡片及工作区顶部显示 `room.name`；旧 `ProjectForm` 没有接入云端，因此只改本地 board 名称不能持久保存。

- 首页卡片提供修改入口，工作区顶部保留名称并增加铅笔按钮，两处使用同一弹窗。支持回车保存、取消和失败重试。
- 沿用邀请管理的创建者权限：仅 owner 可以修改，服务端也校验；成员继续可以编辑画布内容。
- 名称去除首尾空格后必须为 1–80 字，与创建画布保持一致。允许同名，不改变项目编号、邀请链接、成员或内容。
- 增加 `PATCH /api/rooms/:id`，只更新现有 D1 `rooms.name`。保存成功后更新当前账号的列表、顶部标题及备份中的项目名称；其他成员重新打开项目时读取新名称。本次不新增名称实时广播协议。
- 请求失败保留输入并显示错误；保存时防重复提交。迟到响应不能污染已切换的账号，也不能重新打开已经离开的项目。
- 无数据库迁移、无新依赖、无生产写入。与尚未提交的头像和灵感板改动一起保留在现有工作区。

方案选择：采用显式编辑按钮和复用弹窗，入口容易发现且键盘可用。双击名称不易发现，直接行内编辑更容易误触；不采用这两种方式。上述权限及入口是基于现有产品的实现判断，已向用户说明。
