# 桌面灵动岛自由移动与停靠

用户已确认交互预览并要求直接实施，沿用 `feat/qingdan-mcp`、当前账号和画布。

- 标题区域、握柄和侧签可以拖动；按钮、任务和输入不能触发拖动。
- 拖动超过 5px 开始移动；在工作区顶部、左侧、右侧 36px 内释放时吸附。离开边缘恢复横向自由胶囊，无底部吸附。
- 顶部保持横向胶囊、向下展开；左右收成 40px × 136px 侧签，展示图标、轻单和剩余数量，向屏幕内侧展开横排待办。
- 拖动期间收起，释放后恢复钉住状态；不提交、不丢弃输入。沿用悬停展开、移开收起、钉住、任务同步和只读保护。
- 保存停靠边与位置；窗口尺寸变化不累积位置偏移。支持负坐标屏幕、工作区变化和显示器移除，实际内容始终可触达。
- 本地 Node.js >= 24，npm；不改变用户服务、账号绑定、同步协议，不发布远端。

实现采用受限 preload 拖动接口，主进程读取系统光标控制窗口；不把任意窗口句柄或系统能力暴露给页面。侧签和面板分别定义原生可点击区域，使透明间隙可以点击后面的软件。
