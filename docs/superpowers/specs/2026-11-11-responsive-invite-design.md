# 邀请协作按钮的响应式显示

用户已确认：在 `feat/arranged-project-labels` 内实现，先预览，确认后再合并 main。

- 宽屏显示图标与「邀请协作」，较窄显示图标与「邀请」，手机宽度只显示图标。
- 按钮保持单行、固定高度，保留完整的无障碍名称与悬停提示。
- 顶栏优先省略长项目名并收紧间距；必要时将辅助入口的文字收起，保留所有操作入口。
- 延用现有配色和图标。画布与排列模式共用同一顶栏；邀请权限与处理逻辑不变。
- 方案比较：仅禁止换行改动更小，但窄屏仍会拥挤；用户选择随宽度简化显示的方案。
- 以真实浏览器验证 320–1440 像素及断点两侧，邀请按钮不换行、不越界，各操作区域不重叠。

实现选择：使用 1150 / 820 / 600 像素断点，360 像素以下进一步收紧间距，不引入依赖。紧凑顶栏从 1150 像素开始生效，为多人头像和较长的同步状态预留空间。
