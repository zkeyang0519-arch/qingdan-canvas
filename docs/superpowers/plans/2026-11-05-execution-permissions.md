# 批次权限与人工询问实施计划

**目标：** 延续第八步，在轻单选择执行权限，并直接回答 Codex 原生审批与问题。用户已授权本次真实三待办测试使用自动安全审查，并要求完成此功能。

**实现选择：** 沿用现有认证、Runner 连接与原生请求应答。新增独立应答收件箱，避免审批应答更换批次的执行命令身份。权限随提交快照冻结；设置偏好仅供下一次提交预填，不能作为授权本身。

**范围：** 只读、项目内编辑且人工审批、项目内编辑且自动安全审查。默认人工审批，基础权限禁用网络，不加入整体无沙箱模式。总结始终只读。权限变更来自用户提交接口，不能由模型工具自行申请提升。原生命令的单次 accept 可能允许沙箱外执行，因此审批弹窗必须明确说明该次操作可能超出项目目录或默认网络范围；仅用户对具体命令的批准才可转发，不声称批准后仍强制保留原沙箱限制。会话级 grantRoot 和无法完整展示的额外权限不提供同意按钮。
