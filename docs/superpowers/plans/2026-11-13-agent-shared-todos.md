# Agent 待办共享状态与页头按钮修正

**目标**：Agent、排列、画布显示并修改同一份待办；三个页头操作按钮尺寸一致。

**已确认原因**：已绑定的 Agent 清单读取自己的服务端快照，只在本面板移回时覆盖完成状态；执行结束标记还把未完成任务放入已完成组。绑定后的手动创建绕过现有共享画布回调，造成跨视图更新路径不一致。

- [x] 真实 App 集成用例覆盖已绑定/未绑定项目的新建、完成、移回及视图切换；保留旧快照复现不一致。
- [x] Agent 以当前共享画布的条目和完成状态为准；服务端只补充执行规格，尚未同步的条目不可派单。
- [x] 已绑定项目的手动新增使用共享画布回调；独立面板保留原有幂等 API 和恢复流程。
- [x] 新增明确的标记完成操作，和执行选择分开；通过 workspace.toggleBlock 维护 completedAt、同步及撤销。
- [x] 执行结束但未确认完成的条目保留未完成状态；不伪造验收，也不自动派单。后续会话核对恢复独立的待核对折叠区，见 `docs/agent-detail-regression-audit-2026-11-13.md`。
