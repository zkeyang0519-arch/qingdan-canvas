# Codex 会话入口

**目标：** 打开轻单 Agent 即可选择本机 Codex 会话，自动连接电脑并将会话目录关联到当前清单，无需填写执行目录。用户已明确选择：每次提交新建执行会话。

**方案：** 新增只读会话发现接口，不受已登记目录过滤；选择时重新读取真实会话的 cwd，复用现有目录登记、设备配对和清单绑定。保留现有执行协议和批次新会话规则。

**技术：** React、现有本机 Node Runner、Codex app-server thread/list 和 thread/read。

## 约束与取舍

- 沿用当前工作目录的未提交实现，不重置或提交用户其他修改。
- 会话读取需要当前轻单登录；已绑定其他账号的设备不能读取。
- 只展示会话标题、目录和更新时间，不导入会话内容，也不恢复或发送消息到旧会话。
- 只有用户选中会话才登记该目录；选择请求只接受 threadId，目录由本机重新读取。
- 没有轻单项目时用会话目录名创建；有项目时界面明确显示关联目标。已有同目录绑定直接复用，保留项目摘要与历史。
- 不发布线上版本；实际运行中的未确认任务仍由现有绑定占用检查保护。

## 重点检查

分页与搜索不丢失旧会话；目录不存在时不绑定；重复选择不改变绑定 revision；设备首次连接需等待注册完成；页面关闭/账号切换后不继续云端绑定。
