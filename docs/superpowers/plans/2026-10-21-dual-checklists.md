# 画布与双栏排列

用户已明确要求：保留画布，加入原 Agent 左侧清单的功能，移除 Codex 交互，将聊天区域替换为另一个灵感板清单。直接在独立项目中实现，Cloudflare 创建和部署仍由用户操作。

## 设计

- 顶部提供「画布 / 排列」。排列左右等宽，各自选择灵感板，分别显示未完成、已完成、资料和收纳操作。
- 复用现有便签富文本编辑器、备注/删除菜单、引用选择器、收纳框、图片预览和完成动效。迁移原列表样式，不导入 Agent、模型或 Codex 模块。
- 模式、两栏所选灵感板及当前操作栏保存在本机视图偏好中。两种模式使用相同对象、块 ID 和协作通道，切换不改画布坐标或尺寸。
- 默认显示两个不同页面。选择另一栏已打开的页面时互换；只有一个页面时另一栏显示新建灵感板入口。新建、重命名、收纳灵感板可在排列模式完成。
- 全局工具和快捷键作用于最近操作的栏；删除选中行只删除该待办，不删除同一便签的其他行。只挂载当前视图，避免重复粘贴、重复编辑器和键盘监听。
- 所有编辑基于最新状态重新校验页面、对象和锁定状态。图片导入捕获发起时的页面，不因中途切换而写入另一栏。中文输入完成后再切换视图或页面。

## 实施及验证

1. 为本机视图选择、页面写入、按行删除、锁定和画布布局保留编写回归测试；先运行确认尚未实现。
2. 实现独立排列数据操作，复用原清单 UI 为一个可重复挂载的栏组件，接入主工作区与现有协作 API。
3. 运行 npm test、npm run check、npm run deploy:check。仅干跑部署，不调用实际部署。
4. 使用隔离本地数据做双窗口验证：两栏新增/编辑/勾选、备注、引用、图片、收纳/取出、页面切换、切回画布、刷新和另一窗口同步。保存截图和验证记录。
