# 待办作者头像

采用用户已确认的方案：每条待办保存创建者，画布顶部的「作者头像」开关仅影响当前账号在当前画布中的显示，默认开启。个人画布继续可以邀请协作者。

- [x] 作者数据：保存账号 ID 和创建时昵称，服务端核定身份；编辑、勾选、撤销和恢复保留原作者；历史条目显示「作者未记录」。
- [x] 同步与备份：保留作者字段，服务端确认不会产生重复提交或阻碍撤销。
- [x] 界面：复用昵称首字头像，画布与排列视图逐行展示；关闭后仍可在待办操作菜单、备注中查看作者。
- [x] 偏好：按账号和画布保存在浏览器中，默认开启，支持键盘操作。
- [x] 验证：新增数据、同步、UI、双账号真实服务测试；执行 npm test、npm run check、npm run deploy:check。

验证结果：176 项测试全部通过，类型检查、构建和部署预检查通过；代码复审通过。浏览器验证了画布与排列的逐行头像、隐藏后查看作者、刷新记忆、空格切换、新增及撤销，390 像素窄屏顶部开关显示正常。

升级兼容：首次创建作者表时读取历史回执和现存条目，旧回收站恢复保持未知作者；旧客户端继续使用原消息格式，新客户端通过能力参数接收作者。作者表与对象版本、回执写入处于同一事务。

实现位于独立分支 `codex/avatar-toggle`，工作目录 `D:/TODO/qingdan-canvas-avatar-toggle`。原目录 `D:/TODO/qingdan-canvas` 的 `develop` 保留改动前版本，可继续使用它比较效果。无需删除项目或覆盖本地数据；未执行真实部署。

## 补充：上传头像图片

用户明确头像应使用上传图片，昵称首字只作为未上传时的默认显示。沿用当前账号、R2 和画布协作结构。

- [x] 账号设置提供上传、更换、移除头像；本地裁成 256×256，圆形显示，支持 PNG/JPEG/WebP/GIF，原文件限 5 MB。
- [x] 上传只修改当前账号；图片存 R2，D1 保存版本；本人及共享画布成员可读取。
- [x] 成员资料包含离线作者，通过画布消息更新头像；已有待办按作者 ID 显示最新头像，不修改作者归属。
- [x] 首页、在线成员、待办共用图片头像；加载失败回退昵称首字；原开关及查看偏好继续生效。
- [x] 验证上传权限、非法文件、替换移除、实时通知、离线作者、客户端显示和真实浏览器上传；运行完整测试与构建预检查。

补充验证：179 项测试全部通过，类型检查、构建与部署预检查通过。代码复查发现并修复图片处理期间切换账号的上传归属问题，上传请求始终绑定选择图片时的账号，失败不会使新账号退出。独立复查无遗留问题。浏览器实际验证 JPEG 上传及 256×256 输出、移除、无效图片提示、画布和排列中的图片头像、隐藏与刷新记忆。本地测试使用项目截图作为测试图片，未部署到线上。
