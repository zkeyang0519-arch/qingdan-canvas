# 轻单协作画布：基础设计

日期：2026-10-20

从 `D:/TODO/src/canvas` 提取已有画布组件，建立可独立安装、运行和部署的应用。保留便签、清单、图片编辑、灵感板、收纳、平移缩放。原项目和本机数据不迁移、不修改。第一版使用邀请链接加入，后续一起配置 Cloudflare。

## 数据与边界

- React/Vite：复用画布交互，新建画布列表、协作状态和分享界面。
- Worker：同源静态资源、匿名会话、画布成员鉴权、邀请和文件接口。
- Durable Object：每画布一个实例；SQLite 保存对象、版本和操作回执；休眠 WebSocket 接收编辑、广播结果与在线成员。
- D1：画布、成员、会话、邀请摘要和图片元信息。邀请令牌与会话令牌只存 SHA-256 摘要。
- R2：私有图片。每次访问经过画布成员检查，只接收 PNG/JPEG/WebP/GIF，单图最多 10 MiB。

## 协作语义

每个操作包含唯一编号和对象预期版本。批量修改在 DO 内原子提交；重传返回原回执；删除保留版本墓碑。客户端保存当前标签页草稿和未确认操作，重连先收快照再重传。不同对象、不同字段及不同清单事项可以合并；同字段冲突保留本地草稿并要求选择，绝不静默覆盖。

视口、选择、撤销记录属于本地用户。撤销按本地改动反向合并，不恢复整个旧快照覆盖其他成员。图片先上传再提交对象。失败显示具体状态并允许重试。

## 访问

浏览器通过 HttpOnly、SameSite Cookie 持有匿名会话。邀请放 URL fragment，通过 POST 换取成员资格。创建者可以重置邀请；已加入成员保留资格。生产环境创建新画布需创建口令 `CREATE_KEY`；本地显式开发环境免口令。邀请成员可编辑；身份是当前浏览器会话，不是假装已实现账号系统。

本轮只创建本地工程、资源绑定配置、迁移和部署指南，不创建云资源、不发布、不设置付费产品。下一阶段从 Wrangler 登录、创建 D1/R2、替换绑定、迁移、部署到双浏览器验收逐步进行。

## 验收

独立安装与构建；Worker 类型检查及 dry-run；真实本地 workerd + D1 + R2 + DO 集成测试：两名成员同步、房间隔离、未授权访问、重复消息、版本冲突、图片上传/访问、邀请重置、断线重连和持久化。浏览器检查实际画布及控制台。
