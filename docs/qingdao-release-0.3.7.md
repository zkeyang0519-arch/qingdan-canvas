# 轻岛 0.3.7 正式版

## 本版变化

- 将林间苔绿、完整色块流动与清透玻璃应用到真实轻岛；增强玻璃边缘高光和折射，流动限制在仓内。
- 保留不加玻璃的“色块流动”版本。两版均可分别保存配色、小仓颜色、色块数量与流动速度；提供林间苔绿等五套组合。
- 轻岛设置面板加入检查更新、下载进度和下载完成后的重启更新；仍走原生保存、校验、安装流程。
- 保留历史版本外观预览、双仓悬停展开、拖动与停靠、小猫与待办操作。
