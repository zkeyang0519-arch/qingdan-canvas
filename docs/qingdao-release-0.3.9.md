# 轻岛 0.3.9：四季草地

Windows 正式版新增「四季草地」外观。春季使用浅绿草地与粉白花树，夏季使用深绿林荫与蓝紫绣球，配合秋叶、冬雪循环变化。

- 每 72 秒循环四季，换季交叠 5 秒；滚动速度可在 8–60 像素/秒间调节，默认 24。
- 顶部与左右停靠保持植物正立，背景滚动方向与小猫朝向相反；展开待办时保留背景。
- 四张 WebP 随安装包分发，断网时也能加载。播放复用缓存图层，隐藏窗口或减少动态效果时暂停。
- 升级保留原有登录、画布、待办、草稿与外观设置，不自动切换已选的玻璃或色块外观。

## 已有用户升级

在「轻岛设置 → 检查更新」等待 0.3.9 下载完成，点击「重启更新」，然后在「外观」选择「四季草地」。也可以从[统一下载页](https://todo.zky.lol/download/)安装正式版。

Windows 正式版使用安装包里的页面。只刷新网站或重启 0.3.8 不会获得新外观，需要通过本次正式更新升级。此次发布属于 Windows 原版渠道，轻量验证版及其 Mac 安装包继续使用独立渠道。

## 发布验收

发布检查包含更新前保存保护、外观与输入保留、完整回归、安装包资源逐文件比对、四季图片断网加载，以及线上下载页与正式更新源一致性检查。实际发布和升级结果在完成后另行记录。
