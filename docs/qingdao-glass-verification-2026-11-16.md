# 轻岛青透玻璃与本机外观设置

日期：2026-11-16。工作分支：`feat/qingdan-mcp`。

## 范围

- 横向、左侧贴边、右侧贴边的收起双仓与展开列表使用相同的烟色透明玻璃。默认使用预览中选定的 `#55B961`、透明度 `70%`，保留圆润字体、固定小猫和双仓尺寸。
- 「轻岛设置 → 外观」提供原生取色器、四个预设、透明度滑杆、±5 按钮和恢复默认。设置独立存储在 `localStorage` 的 `qingdan.desktop.island-appearance.v1`；不调用工作区更新，不添加数据迁移，不修改待办、账号、草稿或设备绑定。
- 页面初次读取不会自动写入设置；损坏或不可用的存储显示提示。保存失败仍能预览并重试。重挂载、同来源窗口及三种停靠共用保存值。
- 轻微流光只调整玻璃背景位置，不拦截鼠标，不新增轮换定时器。隐藏、拖动、减少动态效果时暂停。

## 保留用户本轮之前的修改

本轮开始时工作树已有响应和固定小猫改动，保留原交互修复；随后按用户要求去掉左右贴边的完成圆圈并居中小猫，横向仍可直接勾选完成。原始文件快照保存于忽略的 `.tmp/glass-baseline-20261116/`，可对照确认原响应逻辑和固定小猫未回退。

- 只有时间／数量小仓悬停 120 ms 才展开全部待办；大仓的背景、标题和小猫用于拖动。
- 悬停展开后原位首击防误点、移动后恢复点击、主动收起保护和键盘回焦继续保留。
- 完成待办即时写入最新有效任务，文字快照保留淡出淡入动画；空待办不显示完成圆圈。
- 隐藏、拖动、减少动态效果对小猫的暂停规则继续保留。
- 新增控件唯一需要的焦点保护：调色器临时取得窗口焦点、透明度输入中移出面板时保留面板；普通窗口失焦、外部点击和主动收起继续按现有规则处理。
- 后续修正：设置与完成记录是当前展开期间的临时视图。轻岛收起后关闭设置并恢复剩余待办视图，下次悬停小仓直接显示待办；已保存的颜色、透明度及任务数据不变。回归测试覆盖横向、左右贴边的主动收起、移出、失焦与拖动。

## 材质与发布边界

保留 `jade-twins` 原生几何协议、2 DIP 抗锯齿余量和内侧高光；未改 `desktop/main.cjs`、`desktop/docking.cjs`、窗口尺寸或命中测试。展开设置时面板有最小高度，避免绝对定位的设置弹层被原生窗口裁掉；小屏幕仍受现有最大高度约束。

浏览器预览有 `backdrop-filter` 的网页内模糊；实际 Electron 透明窗能透出其他软件，但 CSS 不能模糊窗口之外的内容。本轮未切换原生 Acrylic 或重建用户桌面窗口。参考 [Electron 透明窗口说明](https://www.electronjs.org/docs/latest/tutorial/custom-window-styles)。

本轮是源码修改和独立预览验证，未发布线上、打包版本或替换已安装客户端。既有数据目录保持原状。
