# 轻岛小仓悬停与固定小猫验收

开发分支：`feat/qingdan-mcp`。本次修改保存在本地工作区，未发布线上版本，也未替换正在使用的桌面客户端。

## 行为

- 横向及左右贴边布局仅由时间／数量小仓的悬停触发完整待办面板，延迟仍为 120 毫秒。离开小仓或按下鼠标会取消待展开计时。
- 大仓空白、文字和小猫区域均可按住拖动；悬停和单击不展开面板。完成圆圈继续完成当前待办，小仓支持鼠标点击和键盘展开，收起后焦点回到小仓。
- 悬停展开后，鼠标原位的第一次点击不会误操作刚出现的待办；移向目标后可正常操作。主动收起时不会因小仓重新出现在鼠标下方而立即展开。
- 动物固定为 `classic-cat` 小猫，删除随机轮换逻辑及定时器。隐藏、拖动和减少动态效果的暂停规则保留，双仓空态继续显示小猫。
