## 本次行为

- Windows 当前用户安装包，附带匹配的网页资源与六种动物。生产 HTTPS origin 下加载安装包内界面，API 仍访问原服务，保留原 Cookie/IndexedDB 身份。
- 自动检查与后台下载，明确点击后保存、重启安装；禁止普通退出时自动安装。更新源固定，网页不能指定下载地址或执行命令。
- 保存期间同步冻结输入，失败即恢复交互并保留旧窗口。输入按来源/账号/画布/项目持久化，待办提交先等待本机保存再清空输入。
- 收起状态展示当前项目第一条未完成待办，完成后顺延；长文字省略，标题可查看全文。
- 已登记本机现有 profile 路径；源代码启动入口优先启动安装版，旧常驻服务也能通过源码入口转发。安装器不复制或删除实际用户数据。
- 登录期限取所属服务的有效会话期限，不能延长服务端授权；过期或撤销会话仍须重新登录。

安装包是未签名本机测试版，Windows 可能显示未知发布者。GitHub 工作流已编写但本轮未推送、未创建 Release、未部署云端，公开自动更新源尚未启用。后续用户选择暂不签名，工作流已改为允许版本标签发布未签名更新并在 Release 标注；启用签名后仍须完整配置并通过签名检查。两个公开版本间的下载并安装更新尚未端到端验收，不能用独立安装/重启测试替代该结论。

第一次从旧源码版迁移前，旧进程中尚未持久化的输入必须先提交或另行保留，再正常退出旧版。新安装器不能追溯恢复旧进程已经丢失的纯内存文字。从此版本开始的输入支持跨重启恢复。有效 Cookie 接续已用隔离会话验证，未对用户真实账号执行退出、清理或故障注入。
