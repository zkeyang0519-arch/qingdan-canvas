## 六项结果

| 要求 | 实现与核对 |
| --- | --- |
| 输出下方复制按钮 | 聊天、执行过程中的助手正文及最终输出均提供小图标复制按钮；复用剪贴板失败反馈。 |
| 动态用时与最终用时 | 执行中每秒按开始时间更新，结束后使用固定完成时间；续跑更新完成时间。缺少可靠历史时间戳时不编造时长。 |
| 复制、引用仅图标 | 去掉可见按钮文字，保留悬停名称、无障碍名称及复制状态提示；引用继续写入当前草稿。 |
| 待办紧凑与去文案 | 压缩行内边距和操作区占位，移除「可直接提交，也可补充要求」。 |
| 输入框模式、模型和快速模式 | 发送按钮同一行提供「聊天 / Agent」、模型下拉和闪电开关。聊天使用已有服务端模型；Agent 从本机 Codex 查询可用模型，实际向 thread/start、turn/start 传递模型和 fast/default 服务等级。 |
| 待办正文编辑 | 正式工作区只显示正文及保存/取消，修改时精确保留已有执行要求、人工或文件验收条件。诊断入口仍支持高级设置。 |

“Agent 选择”按现有项目能力解释为「聊天 / Agent」工作模式；未增加其他 Agent 引擎。快速模式仅在模型明确支持时可选。设置按账号及项目关联隔离；重试使用原不可变执行请求。右侧权限与输入框执行同步，项目摘要时间及过期标记保留。
