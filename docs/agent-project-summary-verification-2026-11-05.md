## 入口

打开本机轻单的 Agent 功能体验画布，进入 **Agent 验证 → 7 · 项目总结**，选择 **第七步项目总结测试**。页面保留实际摘要与来源；“使用摘要聊天”进入同一项目的第6步。

## 实现行为

- 明确选择已绑定项目后初始化总结；重新打开同一项目或重复初始化不会重复派发。显式新聊天或重新总结创建新的只读 Codex 会话。
- 资料由 Runner 从授权根目录只读采集，Codex基于资料包总结现状、已完成、进行中、待处理、阻碍、验证和不确定项。
- 每次实际启动时采集原生 Git 基线；排队期间前任务的文件变化不阻止只读总结。写任务仍严格检查授权快照的基线。
- 摘要保存版本、生成时间、运行及真实会话来源；失败保留旧摘要，但必须明确点击“使用上次摘要”才用于聊天。
- 摘要变化使依赖旧摘要的聊天建议失效，正在生成的旧结果也不能写入；独立用户要求和明确保存的产物保留。
- 停止总结等待本机确认后才允许重新总结；同一停止请求可以安全重试。
