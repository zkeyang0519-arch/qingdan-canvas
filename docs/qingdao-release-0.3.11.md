# 轻岛 0.3.11

- 在「轻岛设置 → 外观」中选择「四季像素庭院」。大舱里的远山、林木和花草以不同速度平滑后移，春夏秋冬依次交替。可以调节滚动速度或暂停动画。
- 鼠标移到大舱上，拖动角上的双向箭头即可调整尺寸。横拖改宽，竖拖改高，斜拖可以同时调整宽高。顶部、左侧和右侧贴边都支持。
- 点击箭头可打开「大舱尺寸」，用滑杆微调或恢复默认。松手后尺寸保存在本机，换肤和重新打开轻岛时都会沿用。

已有 Windows 正式版用户可以打开「轻岛设置 → 检查更新」，下载完成后点击「重启更新」。首次安装请使用[轻岛下载页](https://todo.zky.lol/download/#original-title)。
