# 本机 Pi 连接器自动维护

本机 Pi 入口的 Codex 对话使用实际协议探测，不再要求逐个添加版本号。固定版本的执行 Runner 仍使用原来的协议版本约束。工具面板只展示轻单直接接入的服务，不读取或复用 Codex 内部配置的其他 MCP 服务。

## 正常连接与更新

连接前发现当前 Codex 程序，读取版本及程序指纹。每个程序指纹使用独立的适配记录。登录状态、工具目录和项目工具选择在实际调用前继续检查，兼容记录不会代替授权。

工具面板分别显示连接与目录读取、只读查询和实际调用的验证状态。Codex 的两个对话工具需要在当前项目启用；连接成功不会自动勾选它们。新适配版本不会继承旧适配版本的执行验证结果。

## Pi 维护流程

连接时遇到明确的协议错误，宿主启动独立 Pi 维护会话，使用当前默认主模型。模型只收到版本、方法、字段名称和允许的映射合同，不接收项目内容、原始错误文本、凭据或其他工具。主模型不可用时保留故障，不自动切换模型服务。

维护会话只能提交声明式字段映射；没有文件、Shell、Codex 或 WAAO 执行工具。候选适配包存放在运行数据目录的 `connectors/` 下，使用内容摘要校验和 SQLite 发布记录。当前自动适配范围是请求字段改名与响应字段路径变化。方法、业务参数值、权限和登录流程变化需要人工适配。

固定验证器检查候选结构，并在独立探测连接中重新读取真实协议和工具目录。候选修改了没有被探测覆盖的方法时，验证失败。验证通过后原子启用；既有连接继续使用它创建时的适配版本。已启用补丁不再适用时先验证上一版本，可用则回滚。

同一故障共用维护任务和持久化租约；最多两次候选尝试，单次维护总时限三分钟。每次 Pi 候选会话最多两次模型请求。失败后可在工具面板点击“重新尝试自动适配”。程序版本变化自动形成新记录。取消业务调用会停止该调用等待，独立维护仍可供之后的调用复用。关闭服务会取消维护进程。

授权、权限和网络错误不会触发代码适配。连接阶段的临时网络错误只进行一次有限重连。自动维护不会发起真实生成来证明生成能力。

## WAAO 独立连接

通过「添加服务」填写 WAAO 官网 MCP 地址并完成轻单自己的授权后，工具面板才列出这条连接。已有轻单独立授权会继续显示，授权过期时保留重新连接入口。WAAO 直连不依赖 Codex，也不读取其 MCP 注册或 OAuth 凭据。

主聊天的 WAAO OAuth 记录按轻单账号和回调入口保存到主聊天目录下的 `waao-auth` 子目录；8790 主入口不再复用 8797 独立试用入口的客户端注册、PKCE 和临时授权文件。旧试用记录保留供旧入口使用。更新后主入口需要完成自己的独立授权，官网应用名称为“轻单”；不复制 Codex 的客户端身份或访问令牌。发现未完成的注册回调与当前入口不匹配时，重新注册匹配的客户端；有效的其他入口凭据不会被静默删除。

WAAO 连接检查在取得工具目录后，还调用服务端 `account_get`。回执必须包含账号和客户端标识，OAuth 模式下客户端标识须与当前注册一致；不满足时不能标记可用。工具面板显示服务端确认的账号，身份或权限范围改变时已加载的旧连接失效。这只证明 WAAO 接受当前账号/应用的授权，具体组织、项目和预算还需使用该连接实际查询，不能借用 Codex 的查询结果证明轻单可访问。

升级时移除原来从 Codex 转接的 WAAO 服务目录和项目工具勾选，保留历史调用记录。用户另外配置过轻单独立授权时，可以继续使用该独立连接，但不会沿用转接连接的工具勾选。旧转接任务不能改用独立连接再次提交，应在 WAAO 官网核对原任务。

官网授权返回本机属于正常的跨站页面导航。主入口代理与 Worker 只对准确的 OAuth 回调路径允许这种 GET 导航，仍检查轻单登录账号、授权 state、PKCE 和 issuer；普通接口、脚本请求与 iframe 不获得此例外。完成页面不包含授权码，并通过同源导航返回原项目的工具面板，避免跨站重定向链再次触发入口限制。

“官网授权”“当前项目使用 WAAO”“WAAO 项目及组织资源范围”分别检查。回调成功后须由 `account_get` 确认账号及 OAuth 客户端；界面展示已核验账号，当前项目只保留一个服务开关，不再逐个勾选 WAAO 工具。开启后自动发现目录、按需加载定义；服务开关不授予 WAAO 权限。旧项目已有 WAAO 选择迁移为开启，空选择保持关闭，新项目授权后仍需开启服务。关闭后旧轮次也不能继续调用，重新开启须加载新句柄。工具拒绝回执保留 WAAO 原因、所需权限和官网处理入口；单项 403 不撤销整个连接，401 才提示重新授权。当前连接未发现组织，只能说明它没有返回可见组织，不能据此断言账号没有组织。授权请求过期时需从轻单重新发起，不能复用旧授权码。

## 原调用恢复

连接问题会在当前项目聊天中显示人工提问卡，也可从「待处理请求」进入。可选择重新检测、打开连接设置或只在当前项目停用该工具；「稍后回答」和备注会保留。回答按项目和请求编号记录，网络回包丢失时核对同一次回答，不重复发起处理。连接恢复不会自动重发已经完成或投递状态不明的聊天消息。

调用记录区分 `not_sent`、`sent`、`received` 与 `unknown`。发送前持久化调用标识及参数摘要，收到结果后保存可复用的完整工具结果。

- 明确在连接阶段失败的调用，可以在恢复连接后使用原调用标识重试。
- 已收到结果的相同调用返回保存的结果。
- 已发送但丢失结果、重启时仍处于发送状态以及历史记录不能确认投递状态的调用，不自动重发。
- WAAO 短片生成继续使用已有幂等提交与原任务查询机制；历史转接回执不会通过另一连接重发。
- 每次恢复仍检查当前项目工具选择、目录和连接来源，已经撤销的工具不能恢复执行。
