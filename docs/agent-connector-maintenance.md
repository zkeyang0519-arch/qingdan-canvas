# 本机 Pi 连接器自动维护

本机 Pi 入口的 Codex 对话与 Codex 托管 WAAO 连接使用实际协议探测，不再要求逐个添加版本号。固定版本的执行 Runner 仍使用原来的协议版本约束。

## 正常连接与更新

连接前发现当前 Codex 程序，读取版本及程序指纹。每个程序指纹使用独立的适配记录。登录状态、工具目录和项目工具选择在实际调用前继续检查，兼容记录不会代替授权。

工具面板分别显示连接与目录读取、只读查询和实际调用的验证状态。Codex 的两个对话工具需要在当前项目启用；连接成功不会自动勾选它们。新适配版本不会继承旧适配版本的执行验证结果。

## Pi 维护流程

连接时遇到明确的协议错误，宿主启动独立 Pi 维护会话，使用当前默认主模型。模型只收到版本、方法、字段名称和允许的映射合同，不接收项目内容、原始错误文本、凭据或其他工具。主模型不可用时保留故障，不自动切换模型服务。

维护会话只能提交声明式字段映射；没有文件、Shell、Codex 或 WAAO 执行工具。候选适配包存放在运行数据目录的 `connectors/` 下，使用内容摘要校验和 SQLite 发布记录。当前自动适配范围是请求字段改名与响应字段路径变化。方法、业务参数值、权限和登录流程变化需要人工适配。

固定验证器检查候选结构，并在独立探测连接中重新读取真实协议和工具目录。候选修改了没有被探测覆盖的方法时，验证失败。验证通过后原子启用；既有连接继续使用它创建时的适配版本。已启用补丁不再适用时先验证上一版本，可用则回滚。

同一故障共用维护任务和持久化租约；最多两次候选尝试，单次维护总时限三分钟。每次 Pi 候选会话最多两次模型请求。失败后可在工具面板点击“重新尝试自动适配”。程序版本变化自动形成新记录。取消业务调用会停止该调用等待，独立维护仍可供之后的调用复用。关闭服务会取消维护进程。

授权、权限和网络错误不会触发代码适配。连接阶段的临时网络错误只进行一次有限重连。自动维护不会发起真实生成来证明生成能力。

## WAAO 独立连接

工具面板可以明确选择“WAAO 官网独立连接”或“使用 Codex 托管连接”。官网直连通过其独立授权连接 MCP，不依赖 Codex 是否可用。选择保存在本机，重启后保留；已有的 Codex 托管授权不被导出或迁移。

首次兼容旧配置时允许检测已有来源；已确认来源及用户显式选择都会固定下来。原任务的回执保存连接来源，同一生成请求不能改用另一来源再次提交。切换来源不会自动扩大当前项目的工具选择。

## 原调用恢复

连接问题会在当前项目聊天中显示人工提问卡，也可从「待处理请求」进入。可选择重新检测、打开连接设置或只在当前项目停用该工具；「稍后回答」和备注会保留。回答按项目和请求编号记录，网络回包丢失时核对同一次回答，不重复发起处理。连接恢复不会自动重发已经完成或投递状态不明的聊天消息。

调用记录区分 `not_sent`、`sent`、`received` 与 `unknown`。发送前持久化调用标识及参数摘要，收到结果后保存可复用的完整工具结果。

- 明确在连接阶段失败的调用，可以在恢复连接后使用原调用标识重试。
- 已收到结果的相同调用返回保存的结果。
- 已发送但丢失结果、重启时仍处于发送状态以及历史记录不能确认投递状态的调用，不自动重发。
- WAAO 短片生成继续使用已有幂等提交与原任务查询机制；切换授权来源不能绕过原任务核对。
- 每次恢复仍检查当前项目工具选择、目录和连接来源，已经撤销的工具不能恢复执行。
