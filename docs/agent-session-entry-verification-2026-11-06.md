# Codex 会话入口验证

范围：本机轻单正式 Agent；用户确认“自动关联项目，每次提交新建会话”。未发布线上版本。

后续修正：本轮遗漏了普通网页 8788 的本机接口访问，相关故障及修复见 [2026-11-07 普通网页接入验证](agent-local-entry-verification-2026-11-07.md)。

## 实现结果

- 普通进入 Agent 立即显示可搜索、分页的 Codex 会话列表，已有历史批次也不跳过选择入口。
- 选择后读取真实会话 cwd，自动配对/连接当前电脑、登记该目录并绑定到界面标明的轻单项目；没有项目时自动按目录名创建。盘符根目录有名称兜底。
- 同目录重复选择复用现有绑定 revision，保留项目摘要及历史；关闭选择、账号变化、失效目录或绑定冲突不会继续派发。
- 选择过程仅读取旧会话元数据；不恢复旧会话、不导入聊天、不启动模型。既有“每次提交新建会话”执行规则保持不变。
- 点击待处理运行通知时直接进入对应项目和执行进度，不被之前选择的其他项目覆盖。

## 自动化验证

- 新增 Runner 发现/选择测试：未配对可列会话、未登记目录可发现、分页、只登记实际 cwd、重复登记复用、目录失效、账号隔离、盘符根目录。
- 新增真实 React 交互测试：打开即读取、自动配对、自动创建项目后继续关联、同绑定复用、失败重试、关闭后忽略迟到响应、搜索与分页。
- 本机路由验证：登录/账号隔离、来源约束、查询边界、拒绝指定任意 root/ownerId。
- 最终完整回归在当前 Codex 固定版本下通过 **896/896**，包括入口导航修复；结果见日志 `.tmp/session-entry-tests-complete.log`。专项测试先复现了缺失入口、首次创建导致中断、盘符根目录名称和跨项目进度跳转问题，再验证修复。
- Worker/Runner 类型检查、Runner 构建与部署 dry run 通过；未执行部署。
