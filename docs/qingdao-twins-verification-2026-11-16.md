# 轻岛雾玉双岛验收

本记录对应发布前的设计接入与验收：已确认的设计接入现有 React 轻岛及 Electron 窗口几何。验收时尚未发布线上版本或替换正在使用的桌面客户端；后续发布与更新另行记录。开发分支为 `feat/qingdan-mcp`。

## 实现

- 横向浅玉大仓：完成圆圈、当前待办、小动物；独立苔绿小仓显示截止时间，无截止时间显示剩余数量。
- 完成操作即时调用原有 `toggleTask` 最新状态校验和 `workspace.toggleBlock`，原文字向上淡出、新文字从下方淡入。动画没有异步数据写入，连续点击不会误完成下一条。
- 左右贴边：上下双仓，标题向屏幕内侧展开。空待办时完成按钮不渲染，上仓从 86 缩至 52，小动物居中。
- 完整面板保留项目切换、钉住、新增、完成恢复、设置、同步反馈和草稿处理；复用轻单圆润字体及本地动物素材。
- 原生 `jade-twins` 区域匹配横向、贴边、预览、完整面板及空态高度；双仓之间的空隙可穿透。`supportsTwinIsland` 能力检测保留旧客户端布局，避免可见控件被旧点击区域裁掉。

## 数据边界

没有修改任务、账号、草稿、同步协议或数据库结构，没有迁移。测试使用独立临时目录，交互预览仅操作内存示例工作区。原有未提交的 Agent 测试改动未覆盖。

## 验证结果

- `npm test`：1677 / 1677 通过，无跳过。
- `npm run check`：通过。
- `npm run deploy:check`：构建及 Worker dry-run 通过，没有执行发布。
- 68 项针对性测试通过：涵盖新旧客户端能力、原生点击区域、重复完成、只读/最新锁定/远端已完成保护、动画卸载、减少动态效果、空态新增和恢复、左右停靠、抓取位置、启动恢复、未提交输入等。
- 第一轮完整测试发现两个启动测试中的全局 `MutationObserver` 引用问题，改为所属 `window.MutationObserver` 后完整复跑通过。
- 使用真实 React 组件完成浏览器检查：横向完成后推进到下一条、截止时间退回剩余数量、新增、完成恢复、钉住及设置；左右贴边、键盘预览和空态隐藏圆圈均确认。页面无控制台错误。
